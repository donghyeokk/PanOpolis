# PanOpolis project page

Static site (single `index.html` + `static/`). No build step.

- `index.html` — the page
- `static/images/` — teaser, pipeline, qualitative figures
- `static/videos/` — walking-sequence demo videos (H.264)

Deploy with GitHub Pages: Settings → Pages → Source: "Deploy from a branch" → `main` / `/ (root)`.
